# Codex Pocket 합성 미리보기

전체 Windows+Android 소스 앱과 별개로 사용할 수 있는 합성 웹 부분집합입니다. 실제 Codex·계정·Tailscale에 연결하지 않으며 OpenAI 공식 제품이 아닙니다.

Node.js22 이상에서 `node --test demo.test.mjs`, `node demo.mjs`를 실행하고 같은 PC의 http://127.0.0.1:47833 을 여세요. 종료는 Ctrl+C입니다. LAN·프록시·공개 터널로 노출하지 마세요. 합성 세션은 인증이 아닙니다.

읽기·검색·결과 이동·코드 복사·생성 이미지·도구·큰 초안·Back/Escape를 확인합니다. Synthetic Preview에서 토큰/초기화 시나리오를 바꿀 수 있습니다. 초기화 예정 경과는 한도 복구의 증명이 아닙니다. 브라우저 저장소에는 합성 입력만 쓰고 검토 뒤 사이트 데이터를 지워 주세요.

실제 전송·새 대화·첨부·로그인·전환·기기 알림/공유·Android 빌드는 이 부분집합에서 지원하지 않습니다. 보이는 미지원 기능은 서버가 거절합니다. 전체 앱의 설치 절차/보안 경계는 저장소 최상위 README와 GUIDE.ko.md에 있습니다. 데모 성공은 native/실기기 검증이 아닙니다.
